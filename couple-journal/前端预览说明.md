# 朝夕 · 前端体验版

双击 start.bat，访问 http://127.0.0.1:8766 。需保持服务运行。

本轮交付是可交互的前端设计，源码独立于原 local-library 项目；旧文件与数据未迁移、未改动。按用户要求，原 8765 服务及当前公网隧道的首页已切换到朝夕前端，旧素材库入口保留在 /library。

当前公网入口：https://properly-segments-arbitration-suited.trycloudflare.com/ 。隧道重启后域名仍可能变化。公网域名、127.0.0.1:8765 和 127.0.0.1:8766 属于不同浏览器来源，体验数据分别保存，不会自动同步。

## 已可体验

- 电脑侧栏与手机底部导航；生活时间线、相册、故事、管理。
- 搜索与年份、月份、标签、故事、素材类型筛选。
- 新建记录、附件预览与排序、编辑、自动草稿；故事创建与收录。
- 记录和附件移入回收站、恢复，文字修改历史。
- 体验文字 JSON 导出（不包含附件，不是完整备份）。

体验数据保存于当前浏览器的 IndexedDB，附件也仅在该浏览器存储。换设备不会同步，清除站点数据会丢失。请不要将其当作正式回忆保存或唯一备份。存储空间由浏览器决定；大体积素材可能保存失败。

## 待后端接入

正式本机文件存储与数据库、真正的上传进度与失败重试、跨设备读取、完整备份恢复、服务端永久删除密钥校验、Live Photo 成对原件识别与预览、媒体格式转换。体验版禁止永久删除，不提供伪安全的前端密钥校验。

纪念日、愿望清单、地图足迹与互相出题只保留后续迭代入口。账号和隐私权限仍待设计。
